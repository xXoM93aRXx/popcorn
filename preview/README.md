# Events list preview

This preview uses the same event-card stylesheet as the Odoo events page, but it does not require Odoo or a web server.

From the `popcorn` addon directory, open it with:

```powershell
Start-Process .\preview\events-list-preview.html
```

You can also double-click `events-list-preview.html` in File Explorer. Refresh the browser after editing `static/src/css/popcorn_event_list_cards.css`.
